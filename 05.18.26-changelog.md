# 05.18.26 Changelog

This changelog summarizes the recent Beyond Bullet Points changes around session restore, guest editing, threaded story assembly, exports, project overview polish, and the shared notepad.

## Session Import and Export

- Added ZIP session import through **Upload Session**.
- The current implementation restores an exported ZIP into the currently open persistent session.
- Exported ZIP files remain useful as portable saved copies of a session.
- ZIP restore replaces the current session's brief metadata, cards, connections, attachment metadata, and shared notes.
- ZIP restore is backward compatible with older archives that do not include notes.
- Remaining follow-ups: create a brand-new session from ZIP and merge a ZIP into the current session.

## Word Document Exports

- Added server-generated `.docx` exports using the `docx` package.
- Project Overview can be exported as a Word document.
- Full canvas/session exports can be saved as a Word document from **Save Doc**.
- The visible document export path now favors Word over PDF.
- Full session DOCX exports include project context, cards, connections, and shared Notes.

## Shared Notes / Notepad

- Implemented the canvas right-panel **Notepad** as a real shared note block.
- Admins and guests with edit access can update notes.
- Read-only users can view notes.
- Notes autosave with visible save state.
- Notes sync through PartyKit across open admin and guest sessions.
- Notes are stored separately from project overview `project_notes`.
- Notes export in DOCX, ZIP, Markdown, and JSON.
- ZIP exports include both `notes.json` and `Notes.md`.
- Remaining follow-up: manually test notepad behavior across admin and guest browsers before marking it fully accepted.

## Guest Editing

- Visitors with edit access can return to the brief from a completed canvas.
- Guests with edit access can save Project Overview edits.
- Guests with edit access can manage uploaded briefing documents.
- Guests with edit access can regenerate cards after confirmation.
- Admin-only dashboard and session management remain admin-only.

## Session Passwords

- Admins can create open or password-protected sessions.
- Password-protected sessions generate a session password during creation.
- Admins bypass session passwords.
- Guests need the correct session password to edit protected sessions.

## Story Generation and Connectors

- Story assembly now uses the current user's thread instead of all visible connections.
- Story assembly creates a current-user story card from connected cards in column order.
- Connections carry thread, color, and owner metadata.
- Multiple users can connect the same card pair without overwriting each other.
- Users can show or hide other people's story threads.
- Individual connection strings can be selected and deleted with Delete or Backspace.
- Remaining follow-up: drag an existing connector off a card to disconnect it.

## Chat and Project Overview Polish

- Removed the old canvas chat **Generate background description** starter button.
- The Create Project Brief flow starts with an invitation before moving into the questionnaire.
- The project overview panel is collapsed by default in the canvas right panel.
- Replaced ambiguous chevrons with clearer plus/minus expand controls.
- Added visible **Save Doc** and **Save Canvas** controls based on Shahid's mockup direction.
- Added unsaved-change handling for project overview edits in the brief flow.
- Remaining follow-up: chat should explicitly ask "Would you like me to add this to the overview?" before applying generated overview text.
- Remaining follow-up: present questionnaire prompts as highlighted agent-style prompt blocks near the chat bar.

## Card and Brief Generation

- Removed the old synthesize action from the card notes panel.
- Brief generation now uses all usable uploaded sources instead of silently limiting the prompt to the first eight uploads.
- Initial card generation now carries questionnaire context into first-run cards, including role-oriented inputs such as "You are".
